# Scope

## In Scope
- Multi-role web platform (Student, Faculty, Placement Cell, Admin)
- 9-agent AI workforce with orchestration
- RAG over institutional knowledge
- ML prediction services with explainability
- Timetable optimization
- Immutable AI decision audit logs
- Synthetic data generation for low-data scenarios
- Free-tier deployable architecture

## Out of Scope
- Biometric attendance hardware integration
- Paid LLM APIs, paid observability, paid MLOps
- ERP-grade finance/payroll modules
- Native mobile apps (web-first in this project)
